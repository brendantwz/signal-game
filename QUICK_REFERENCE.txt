┌─────────────────────────────────────────────────────────────────────┐
│ SETUP (5 MINUTES)                                                   │
└─────────────────────────────────────────────────────────────────────┘

1. Open /admin → Click "Create New Game"
2. Display /screen on big TV/projector  
3. Share access code with players
4. Wait for 3+ players to join
5. Click "START GAME" when ready

┌─────────────────────────────────────────────────────────────────────┐
│ CONTROL PANEL BUTTONS                                               │
└─────────────────────────────────────────────────────────────────────┘

[ CH1: STORY ]    → Show Chapter 1 narrative
[ CH1: VOTE ]     → Open Chapter 1 voting
[ CH2: STORY ]    → Show Chapter 2 narrative  
[ CH2: VOTE ]     → Open Chapter 2 voting
[ CH3: STORY ]    → Show Chapter 3 narrative
[ CH3: VOTE ]     → Open Chapter 3 voting
[ SHOW RESULTS ]  → Display final scores & hacker reveal
[ END GAME ]      → Finish session (can't undo!)

┌─────────────────────────────────────────────────────────────────────┐
│ GAME FLOW                                                           │
└─────────────────────────────────────────────────────────────────────┘

STORY PHASE:
  • Read narrative aloud (2-3 min)
  • All devices show story text
  • Click next when ready

VOTE PHASE:
  • Players make secret choices (1-2 min)
  • Admin shows vote progress %
  • Big screen shows who has voted
  • Proceed when 100% complete

RESULTS:
  • Final scores revealed
  • Hacker identity exposed
  • Discussion time!

┌─────────────────────────────────────────────────────────────────────┐
│ TRINITY SYNC                                                        │
└─────────────────────────────────────────────────────────────────────┘

When you click ANY button in admin:
  → Big screen updates INSTANTLY
  → All player devices update INSTANTLY
  → Target: Sub-100ms synchronization

┌─────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                     │
└─────────────────────────────────────────────────────────────────────┘

Player disconnected?

  → Progress/role preserved

Screen not updating?

  → Check game ID in URL

Vote stuck?

  → Remind them verbally
